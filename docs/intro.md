# Welcome to BunSane

BunSane is a TypeScript framework for building APIs with Bun. It uses an Entity-Component model stored in PostgreSQL and provides automatic GraphQL generation.

## What is BunSane?

BunSane helps you build web APIs quickly. It handles the database setup, GraphQL server, and common tasks so you can focus on your app's logic.

Key features:
- Stores data using Entities and Components in PostgreSQL
- Builds GraphQL APIs automatically from your code
- Includes tools for logging, scheduling, and more
- Works with Bun for fast performance


:::danger

Bunsane are currently in Experimental stage and still in active development.
I don't know if this concepts will fit or not in Web Development space so feel free to give some suggestions or critiques.

:::
